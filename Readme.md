# 📱 Cheremsha Boot Logo (TWRP)

Кастомный логотип загрузки для телефона в виде прошиваемого архива.

## ⚡ Установка

1. Скачай `.zip` файл из раздела [Releases](https://github.com/Jasurios/CheremshaLogo/releases).
2. Загрузись в кастомное репозиторий (TWRP / OrangeFox).
3. Нажми **Install**, выбери скачанный архив и прошей его.
