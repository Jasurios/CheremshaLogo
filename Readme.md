# 📱 Cheremsha Boot Logo (Magisk, KernelSu)

Кастомный логотип загрузки для телефона в виде архива.

## ⚡ Установка

1. Скачай `.zip` файл из раздела [Releases](https://github.com/Jasurios/CheremshaLogo/releases).
2. Загрузись в менеджер рута.
3. Нажми **Install**, выбери скачанный архив и прошей его.
4. Перезагрузи телефон.
