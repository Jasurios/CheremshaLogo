# 🌿 Cheremsha Logo

Официальный репозиторий с графическими ассетами и исходными файлами логотипа для проекта **Cheremsha**.

---

## 📁 Содержимое репозитория

*   `logo.img` — Основной тяжелый исходник логотипа в высоком разрешении (64 МБ).
*   **Исходный код** — Распакованные рабочие файлы проекта в ветке `main`.
*   **Архив релиза (.zip)** — Готовый скомпилированный архив со всеми форматами логотипа. Его можно скачать в один клик в разделе [Releases](https://github.com/Jasurios/CheremshaLogo/releases).

---

## 🚀 Как скачать материалы

### 1. Быстрый вариант (Рекомендуется)
Если вам нужны только готовые картинки для использования, перейдите на страницу **Releases** справа и скачайте прикрепленный `.zip` архив. Там всё разложено по папкам.

### 2. Полный вариант (Для дизайнеров/разработчиков)
Если вам нужны исходники и тяжелые файлы вроде `.img`, склонируйте этот репозиторий к себе на компьютер:

```bash
git clone [https://github.com/Jasurios/CheremshaLogo.git](https://github.com/Jasurios/CheremshaLogo.git)
